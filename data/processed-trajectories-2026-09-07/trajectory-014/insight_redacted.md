# I001

Evidence: L002, L003, L004

When a requested workflow is not installed globally, a user-identified project-local implementation may still be authoritative. Checking the specified local location before declaring the workflow unavailable avoids premature refusal while preserving its safeguards.

# I002

Evidence: L005, L013

Shared or network-mounted workspaces can violate assumptions about responsiveness and atomic filesystem operations. Running an unchanged executable copy and mutable workflow state in private local storage can isolate those limits while preserving the workspace as the source and destination.

# I003
