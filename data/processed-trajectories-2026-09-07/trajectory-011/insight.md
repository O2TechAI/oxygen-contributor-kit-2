Evidence: L004, L009, L010, L012, L019

Completing an unfinished technical deck can require reframing its argument before filling its placeholders. Here, evidence that ranking differences were modest while source distinguishability and proxy disagreement were large supported a stronger evaluator-validity thesis, which then determined the slide arc and completion criteria.

# I002
Evidence: L007, L008, L009, L010, L011, L013

Model rankings should not stand in for construct validity when rankings change across judges or benchmarks and correlate weakly with a direct diagnostic. A more defensible evaluation presents interpretable diagnostic components, judge sensitivity, common-support uncertainty, and missingness alongside any composite or leaderboard.

# I003
Evidence: L015, L016, L017, L018

Matched specificity can coexist with obvious behavioral artificiality. Examples that hold topic or profile fit constant while exposing differences in hesitation, revision, error, and interaction length make this failure mode legible, provided they are paired with aggregate evidence and phrased within what the metric actually measures.

# I004
Evidence: L011, L013, L017, L028

Precise language is part of statistical validity. Calling a style-only reward “quality,” treating distance from indifference as correct source identification, or omitting same-conversation profile construction would strengthen claims beyond the evidence; correcting those labels preserves the usefulness of a negative result without hiding its limits.

# I005
Evidence: L012, L013, L014, L018, L019

Iterative grilling works best when each round closes a different decision frontier: audience and thesis, metric and evidence policy, narrative and statistical presentation, then example selection. Restating the consolidated specification for final confirmation reduces the chance that implementation silently reopens settled choices.

# I006
Evidence: L003, L020, L021, L023, L024

When the preferred presentation integration is unavailable, a shared scene specification can preserve editability and cross-format consistency. The fallback still needs explicit dependency and module-resolution checks, because package installation success does not guarantee that the documented import path works in the local runtime.

# I007
Evidence: L024, L025, L026, L027, L028

Structural success is insufficient for presentation QA. Archive validity and slide counts did not reveal collisions, clipping, tight multiline text, or a misleading sample-size citation; rendered visual inspection plus a separate numeric/content audit caught defects from distinct failure classes.

# I008
Evidence: L005, L006, L011, L013, L022, L027

Reusing completed local evidence late in a presentation workflow limits fresh experimental variability, but it requires an explicit comparability audit. Run coverage, common support, judge roles, metric scope, and stale documentation must be reconciled before values from separate artifacts can safely share a slide.
